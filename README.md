# AI Engine & LLM Observatory 🚀

Real-time global API health, latency monitor, and telemetry dashboard built with React, Vite, Tailwind CSS, and Recharts.

## ✨ Features
- **Multi-Region Telemetry:** Switch between US, EU, and Asia testing nodes.
- **Live Latency Probing:** Real-time ping testing for OpenAI (ChatGPT), Anthropic (Claude), and Google (Gemini).
- **Interactive Area Charts:** Visualizing response times over time using Recharts.
- **30-Day Uptime History:** Reliability status bars for each LLM provider.
- **System Terminal Log:** Real-time event console capturing network states and responses.

## 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Tooling:** PostCSS, Oxlint
